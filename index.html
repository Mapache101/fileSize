IGCSE Data Representation Cheat Sheet

Understand the crucial difference between Decimal (Base 10) vs Binary (Base 2) units and file size math.

Decimal Units (Base 10)

Used by manufacturers for hard drives, flash drives, and general speeds. Powers of 1000 ($10^3$).

1 Kilobyte (KB) 1,000 bytes
1 Megabyte (MB) 1,000 KB (10⁶ bytes)
1 Gigabyte (GB) 1,000 MB (10⁹ bytes)
1 Terabyte (TB) 1,000 GB (10¹² bytes)

Binary Prefixes / IEC (Base 2)

Used in computer memory (RAM) and precise IGCSE data storage calculations. Powers of 1024 ($2^{10}$).

1 Kibibyte (KiB) 1,024 bytes ($2^{10}$)
1 Mebibyte (MiB) 1,024 KiB ($2^{20}$)
1 Gibibyte (GiB) 1,024 MiB ($2^{30}$)
1 Tebibyte (TiB) 1,024 GiB ($2^{40}$)

Essential IGCSE Formulas

Bits to Bytes: Divide by 8 (8 bits = 1 byte)
Bytes to Bits: Multiply by 8
Image File Size: $\text{Width} \times \text{Height} \times \text{Colour Depth (bits)} \div 8$
Storage Capacity Fit: $\text{Total Memory Size (bytes)} \div \text{File Size (bytes)}$
